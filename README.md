# project-four-OMMIMA-IQBAL

DecodeLabs Internship - Form Design & Validation Engine (Project 4)
This repository contains the Form Design & Validation Engine project developed during the DecodeLabs Frontend Development Internship.

🚀 Project Overview
A production-grade, secure web form validation engine built to explore the boundaries between native HTML5 constraints and custom JavaScript intelligence. It focuses on strict regular expression gating, total accessibility compliance, and intelligent dynamic feedback.

✨ Key Features
PreventDefault Shield: Intercepts raw form submissions instantly to run custom JavaScript validation pipelines.

Regex Logic Gates: Implements a strict password policy and email pattern matching to guarantee absolute data integrity.

Dynamic State & ARIA Compliance: Automatically toggles visual feedback classes and manages screen-reader attributes (aria-invalid and aria-describedby).

Packaged JSON Payload: Dynamically formats and displays captured valid form data cleanly upon successful submission.

🛠️ Tech Stack
HTML5 (Semantic structure and form constraints)

CSS3 (Branded styling, responsive layout, and dynamic state styling)

Vanilla JavaScript (ES6+) (Event interception, regular expression testing, and payload packaging)
